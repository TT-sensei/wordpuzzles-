# ことばさがし

小学生向けの「ことばさがし（ワードサーチ）」問題を作成できるWebツールです。テーマを選ぶだけで問題が作れ、自分で単語を入力してオリジナルの問題にもできます。作った問題と答えは、そのまま印刷して配れます。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/wordpuzzles-/)

## できること

- テーマは6種類（おまかせ／どうぶつ／たべもの／しぜん／がっこう／くらし）
- 出題する単語の数は、5語・10語・15語・20語・30語から選択
- 単語リストを自由に入力できる（1行に1つ）。ひらがな・カタカナどちらでもOK
- むずかしさは3段階
  - かんたん：よこ・たてのみ
  - ふつう：ななめもあり
  - むずかしい：ぎゃくむきもあり
- マスの大きさは自動、または12×12／15×15／18×18／20×20から選択
- 「問題を印刷」と「答えを印刷」の2種類を印刷できる

## 対象

小学生の国語・言葉遊びの学習に。授業や自学で使うプリントづくりにも使えます。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- 外部API・外部フォントなどの外部通信なし（ブラウザだけで動作）
